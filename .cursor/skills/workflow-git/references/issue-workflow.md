# Issue Workflow

## 起票前に確認すること

- 何を決めたい Issue か、何を実装したい Issue か
- 対象が `terraform` / `cloudflare-pages` / `workers` / `dns` / `secrets` / `ci-cd` / `observability` / `docs` のどれか
- 既存 Issue や spec と重複していないか

## 停止条件

- 起点となる要求 Issue が曖昧
- 対象 resource / Terraform scope / docs scope が決められない
- 完了条件を検証可能な文で書けない
